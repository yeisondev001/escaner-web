CríticaArchivo .env expuesto

El .env suele tener contraseñas de base de datos, llaves de API y secretos.

Cómo arreglarlo: Borrar el archivo del servidor o bloquear su acceso, y cambiar cualquier contraseña o llave que contenga.

MediaEl sitio se puede meter dentro de un iframe (clickjacking)

https://tienda.demo.test/

Sin X-Frame-Options ni frame-ancestors, otra página puede mostrar este sitio oculto y engañar al usuario para que haga clic.

Cómo arreglarlo: Enviar X-Frame-Options: DENY (o SAMEORIGIN), o en la CSP: frame-ancestors 'none'.

Más información: owasp.org

MediaFalta Content-Security-Policy (CSP)

https://tienda.demo.test/

Sin CSP, si hay una falla de XSS el navegador ejecuta cualquier script inyectado.

Cómo arreglarlo: Definir una política, por ejemplo: default-src 'self'; y ajustar según los recursos que use el sitio.

Más información: owasp.org

MediaFalta Strict-Transport-Security (HSTS)

https://tienda.demo.test/

Sin HSTS, un atacante en la misma red puede forzar al navegador a usar HTTP en la primera visita.

Cómo arreglarlo: Enviar: Strict-Transport-Security: max-age=31536000; includeSubDomains

Más información: owasp.org
